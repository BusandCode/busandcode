## 🚀 Currently Building

### Clune

A **fintech + marketplace platform for tricycles and e-bikes in Nigeria.**

Clune allows customers to purchase vehicles outright or through **Flex Pay installments**, while providing the infrastructure needed to manage payments, orders, KYC, wallets, and fulfillment.

**Built with:**

`React Native` · `Expo` · `React` · `TypeScript` · `Node.js` · `Express` · `PostgreSQL` · `Prisma` · `Paystack` · `Dojah`

### Key Features

* 🚲 Tricycle & e-bike marketplace
* 💳 Paystack payments
* 💰 Wallet system
* 📆 Flex Pay installment plans
* 🔐 KYC verification
* 👥 Role-based admin dashboard
* 📦 Order & delivery management
* 🔔 Push notifications
