# 🔧 Engineering Principles

### Build for the user

A technically impressive application is still a bad product if the user struggles to use it.

### Keep things maintainable

I prefer clear structures, reusable components, predictable state management, and code that another developer can understand.

### Solve the actual problem

I try to avoid unnecessary complexity and focus on what the product actually needs.

### Think beyond the interface

A good interface is only one part of a product.

I like understanding how the frontend, backend, database, integrations, and infrastructure work together.

### Ship and improve

I believe products become better through continuous development, testing, feedback, debugging, and iteration.
